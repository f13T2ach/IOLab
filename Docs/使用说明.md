# IOLab 【成龙智慧实验室】

## 一.套件内容
>1. IOLab 上位机软件
>2. ESP32主控板
>3. 主通信线
>4. 传感器套件
>> 1. 光强度
>> 2. 氧气
>> 3. 二氧化碳
>> 4. pH计
>> 5. 氧化还原
>> 6. 氯离子
>> 7. 盖革计数器
>5. 实验室安全套件


## 二.开始实验
1. 在Windows操作系统中安装IOLab上位机软件(详情参阅上位机软件使用教程)
2. 取出ESP32主控版并将主控板通过串口连接至计算机
3. 从传感器套件中取出实验所需的传感器
4. 传感器按照标识进行连接
5. 安装实验室安全套件
6. 启动 IOLab 开始实验

## 三.结束实验
1. 将主控板与计算机连接断开
2. 从主控板上取下传感器
3. 按照传感器需要进行相应清洁
4. 拆除实验室安全套件
5. 关闭软件保存实验数据
6. 完成实验
